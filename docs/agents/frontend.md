# Agente: Frontend — Advance Check

Implemente a experiência mobile-first do promotor conforme PRD, plano e guia UX/UI. Antes de codificar, inspecione a aplicação/repositório atual e identifique componentes reaproveitáveis.

Priorize clareza operacional, acessibilidade, uso com uma mão, recuperação de erros e estados reais de sincronização. Use Outfit e a identidade Advance como base, sem reproduzir densidade ou hierarquia problemática do legado. Formulários, seleções e filtros permanecem na tela/contexto sempre que o guia definir. Não invente dados nem comportamento de backend. Trate contratos de API como fonte explícita; comunique lacunas ao coordenador.
